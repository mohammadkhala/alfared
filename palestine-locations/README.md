# Palestine Locations Database

قاعدة بيانات مواقع فلسطينية جاهزة للاستيراد للتطبيقات والمتاجر وأنظمة التوصيل.

## التحديث الأخير

تم توزيع مناطق الداخل الفلسطيني على مدن/مراكز داخلية بدل تركها كلها تحت تصنيف واحد باسم `الداخل الفلسطيني`.

داخل `locations.json` ستجد لكل منطقة من الداخل الحقول التالية:

- `governorate`: بصيغة `الداخل الفلسطيني - اسم المدينة/المركز`
- `inside_city`: المدينة أو المركز الذي تتبع له المنطقة تشغيليًا
- `inside_city_id`: معرف المدينة/المركز
- `parent_id`: يشير إلى المدينة/المركز للمناطق التابعة

## الملفات

- `locations.json`: الملف الرئيسي الموحد.
- `inside_cities.json`: قائمة المدن/المراكز المستخدمة لتجميع مناطق الداخل.
- `governorates.json`: المحافظات/المناطق العامة.
- `delivery_zones.json`: رسوم التوصيل.
- `mysql.sql`: سكربت MySQL جاهز للاستيراد.
- `mongodb.json`: نسخة MongoDB.
- `locations.csv`: نسخة CSV.
- `locations.xlsx`: نسخة Excel.

## تنبيه مهم

الأسماء والتصنيفات مناسبة كبداية تشغيلية لمشروع توصيل، لكن الإحداثيات ورسوم التوصيل تقريبية وتحتاج مراجعة ميدانية قبل الاستخدام الإنتاجي.
